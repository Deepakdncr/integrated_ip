## Running on Android

If `flutter run` fails because `JAVA_HOME` is not set, use the helper script:

```powershell
.\run_flutter_android.ps1
```

This script attempts to find a locally installed JDK and set `JAVA_HOME`
for the current session before launching `flutter run`.

If you want to run the app immediately on Windows instead of Android, use:

```powershell
.\run_flutter_windows.ps1
```
